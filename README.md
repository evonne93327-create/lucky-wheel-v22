# 命運轉盤 (Lucky Wheel)

一個純前端的抽籤轉盤 PWA，開啟網頁就能用，不需要後端、不需要安裝套件。所有題庫、顏色與設定都存在瀏覽器本機的 `localStorage`，可安裝到手機桌面並離線使用。

介面語言為繁體中文（`zh-TW`）。

## 功能

### 前台（轉盤頁）
- **多組轉盤**：以下拉選單切換不同題庫，各自獨立保存。
- **旋轉抽選**：Canvas 繪製轉盤，點「旋轉命運」或中央魔杖按鈕開始，約 4 秒後跳出結果彈窗，並附上音效與震動回饋。
- **抽出後自動隱藏**：勾選後，抽中的項目會自動移到隱藏清單，適合不重複抽選的場景。
- **結果暫存區**：每次抽出的結果會自動累積在文字框中，可一鍵複製全部或重置。
- **日 / 夜 / 跟隨系統** 三段主題切換。

### 後台管理（題庫編輯）
- **轉盤管理**：新增、重新命名、刪除轉盤。
- **單筆新增**：輸入「名稱」與選填的「描述」。
- **批量匯入**：支援兩種格式，可混用：
  1. `名稱,描述` 寫在同一行，中間以半形逗號分隔；
  2. 「名稱」與「描述」分成兩行，項目之間以空行分隔。

  可選擇匯入前檢查重複項目。
- **項目清單**：分為「顯示中」與「已隱藏」兩區，支援搜尋、排序（原始順序 / 首字母 / 字數，可切換升降冪）、逐筆編輯與刪除、全部取消隱藏、批量刪除已隱藏項目。
- **轉盤顏色**：日 / 夜間模式各自一組色盤，最多 10 色，可重置為預設或套用到所有轉盤。

### 機率調整
- 為每個項目設定**權重**或直接輸入**百分比**，兩者自動雙向換算（四捨五入至小數點第三位）。
- 可選擇讓**轉盤外觀跟著機率改變**（扇形大小依權重分配），或維持等分外觀但實際依權重抽選。
- 一鍵全部重置為權重 1（公平機率）。

### 全站配色管理（隱藏功能）
在後台頁面連續點擊主題切換按鈕 **5 次**，即可進入全站 CSS 變數編輯面板，分別調整日間與夜間模式的配色，支援匯入 / 匯出 JSON。

### 匯入 / 匯出
| 動作 | 格式 | 說明 |
| --- | --- | --- |
| 匯出當前轉盤題庫 | JSON (`type: xp_wheel_single`) | 含項目與日夜色盤 |
| 匯出所有轉盤題庫 | JSON 陣列 | 完整備份 |
| 匯出當前 / 所有轉盤顏色 | JSON (`wheel_colors_single` / `wheel_colors_all`) | 只含配色 |
| 匯入 | `.json` / `.txt` | 共用同一個匯入按鈕，自動辨識內容類型 |

匯入 `.txt` 時可選擇「加入目前所選轉盤」或「建立為新轉盤」；匯入前會先跳出預覽視窗確認解析結果，並可自動略過重複項目。

## 檔案結構

```
index.html    頁面結構：前台、後台、配色面板、機率面板與各式彈窗
app.js        全部邏輯：轉盤繪製、抽選、題庫 CRUD、匯入匯出、主題與機率
style.css     樣式與 CSS 變數（日 / 夜間主題）
manifest.json PWA 設定（名稱、圖示、standalone 顯示）
sw.js         Service Worker，快取靜態資源以支援離線使用
favicon.png   網站圖示
icon-192.png / icon-512.png    PWA 圖示（192 / 512）
```

## 使用方式

本專案為純靜態網頁，沒有建置步驟。

直接以瀏覽器開啟 `index.html` 即可使用大部分功能；但 Service Worker（離線快取）需要在 `http://` 或 `https://` 下才會註冊，建議用簡易伺服器啟動：

```bash
# 擇一即可
python3 -m http.server 8000
npx serve .
```

接著開啟 <http://localhost:8000>。

**部署**：把整個資料夾上傳到任何靜態空間（GitHub Pages、Netlify、Vercel…）即可。在手機瀏覽器開啟後選擇「加入主畫面」，就能當成獨立 App 使用。

## 資料儲存

所有資料只存在使用者自己的瀏覽器，不會上傳任何地方。清除瀏覽器資料會一併清除題庫，請善用匯出功能備份。

| `localStorage` 鍵 | 內容 |
| --- | --- |
| `xp_wheels_store_v1` | 所有轉盤（標題、項目、日夜色盤） |
| `xp_active_wheel_id` | 目前選取的轉盤 |
| `xp_auto_hide_v1` | 「抽出後自動隱藏」開關 |
| `xp_result_stash_text_v1` | 結果暫存區文字 |
| `wheel_theme_mode_v3` | 主題模式（`auto` / `light` / `dark`） |
| `wheel_custom_global_themes_v1` | 全站自訂配色 |
| `wheel_cheat_visual_v1` | 「轉盤外觀跟著機率改變」開關 |

## 瀏覽器需求

現代瀏覽器即可（Chrome、Edge、Safari、Firefox）。使用到 Canvas、CSS 變數、`localStorage`、Web Audio API（音效）、Vibration API（震動，僅部分行動裝置支援）與 Service Worker（離線快取）。
